# Data extraction
Data most recently downloaded 16 August 2023

## Summary of Data provided by Yukon
Summary provided by Kristina Beckmann (Kristina.Beckmann@yukon.ca)

July 2023

### Aishihik caribou

New collaring program with live feed. Collars were put on in November 2022 & Feb/March 2023. Will be doing a census survey on this herd this fall.

### Clear Creek caribou

Older program that is now complete. However – we will be putting more collars on Clear Creek animals this coming winter.

### Coal River caribou

Newer collaring program with live feed. Did a census survey last fall on this herd.

### Hart River caribou

Combination of new and old collars. This herd always has some collars on it, and many animals get recaptured and re-collared. A mix of collar types/brands are used on this herd. Live feed for current Vectronics collars.

### Klaza caribou

Old program that is now complete. However, we will be putting 40 more collars out on Klaza animals this winter.

### Kluane caribou

Old program that is now complete.

### Little Rancheria caribou

#### Little Rancheria caribou – B.C. collars NO SHARING

his has all the BC owned collars. The “no sharing” part is more for us, so we do not share with anyone else in future unless we have permission from BC. This is mostly live feed, but there are 4 Lotek collars as well, one of which is still active.

#### Little Rancheria caribou – Yukon collars

These are all the Yukon owned collars, all live feed.

### Nahanni caribou

Older study that is now complete.

### Southern Lakes caribou – Updated

This study is comprised of three herds: Carcross, Ibex and Laberge. There are two studies in here, one older one that is complete, and a more recent one that is almost complete – all collars were supposed to drop this spring, but some did not and they are still moving around. These herds will likely become like Hart River in that they will have an ongoing collaring program, this is because they are within close proximity to Whitehorse with lots of disturbance in their range. We are also in the process of establishing a management plan for these herds with 8 other governments (6 FNs, B.C. and Parks Canada). No live feed, as the active collars are all Lotek. Current until March 31, 2023.

### Tay River caribou

Combination of newer and old programs, some collars still active with live feed.

### Wolf Lake caribou

Newer collaring program with live feed. We performed a census on this herd last fall.


Each study will have GPS data and reference data available for download. All timestamps should be in UTC. The one exception might be the Kluane reference data. I have had an ongoing error message when uploading it and have not resolved it yet. Kluane GPS data should be fine though.


The reference data should be all up to date with deployment on/off dates (I update these when I can), and many animals have deployment end types. If there is no deployment end type specified, then we don’t have that information.


Herds that we are planning to put collars on this upcoming winter are as follows: Klaza (40 collars, including 10 solar collars), Pelly Herds (20 collars), Clear Creek (30 collars), Hart River (14 collars)
